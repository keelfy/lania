# Форматирование

В этом разделе вы можете найти информацию о том, каким образом можно форматировать ваши сообщения в чате.

## Текст

В чате можно использовать следующие теги для форматирования текста:

- `**текст**` → **текст**
- `*текст*` → *текст*
- `~~текст~~` → ~~текст~~
- `__текст__` → <u>текст</u>
- `||он умер в конце драйва||` → преобразуется в скрытый текст, которые будет виден только при наведении на него курсора мыши в чате.

## Упоминание игроков

В чате можно упоминать игроков, используя их никнейм с символом `@`. Пример: `@keelfy`.

При упоминании игрока, ему придет звуковое уведомление и ник будет выделен в чате.

## Ссылки

Ссылки, отправленные в чат, начинающиеся с протокола (`http` или `https`) будут автоматически преобразованы в кликабельные ссылки.

- `https://lania.gg` → [lania.gg](https://lania.gg)

## Плейсхолдеры

Вы можете отправлять в чат специальные коды, которые будут отображаться в чате в виде настоящего значения.

- `%ping%` → Пинг игрока, который отправил сообщение
- `%tps%` → Текущий TPS сервера
- `%online%` → Количество игроков онлайн
- `%coords%` → Координаты игрока, который отправил сообщение
- `%stats%` → Здоровье, еда, защита и другие данные игрока, который отправил сообщение
- `%skin%` → Скин игрока, который отправил сообщение
- `%item%` → Предмет в руке игрока, который отправил сообщение
