# Скины

На сервере работает плагин [SkinsRestorer](https://skinsrestorer.net/docs/features): поставить свой скин можно и без лицензии.
Владельцам лицензии ничего делать не нужно &mdash; их скин подтягивается автоматически.

## На сайте

Проще всего сменить скин в [настройках профиля](/profiles/settings), в карточке «Скин»:

- **Файл** &mdash; перетащите PNG 64x64 (или 64x32) и посмотрите превью. Модель с тонкими руками определяется сама, её можно переключить;
- **Лицензионный ник** &mdash; скопировать скин лицензионного аккаунта;
- **Сбросить** &mdash; вернуть скин лицензии или стандартный.

Если вы в игре, скин сменится сразу, без перезахода. Скин свой в каждом сезоне: он применяется к сезону, выбранному в карточке украшений. Этот же скин показывается на сайте &mdash; в профиле и в списке сообщества.

## Скин другого игрока

Если нужный скин уже стоит у какого-то лицензионного аккаунта, достаточно его никнейма:

```
/skin set Notch
```

Также можно открыть меню `/skins` и выбрать скин из каталога.

## Свой скин из файла

1. Подготовьте файл скина: **PNG**, размер **64x64** (или старый формат 64x32), не больше 3 МБ. HD-скины не поддерживаются;
2. Откройте страницу [skinsrestorer.org/upload](https://skinsrestorer.org/upload) и загрузите файл;
3. Проверьте превью и нажмите **Generate /skin url**;
4. Скопируйте сгенерированную команду и вставьте её в чат игры.

Если файл уже лежит в интернете и открывается по прямой ссылке на `.png`, можно сразу:

```
/skin url "https://example.com/myskin.png"
```

Для тонких рук (модель Alex) добавьте в конце `slim`:

```
/skin url "https://example.com/myskin.png" slim
```

<Callout type='info'>
  Ссылку всегда оставляйте в кавычках. Если вы изменили файл скина &mdash; загрузите его заново: старая ссылка продолжит показывать прежний скин.
</Callout>

## Редактирование текущего скина

1. Введите `/skin edit` &mdash; в чат придёт ссылка на редактор;
2. Измените скин и нажмите **Save**;
3. Нажмите правой кнопкой мыши на 2D-развёртку скина слева и выберите «Сохранить изображение как»;
4. Загрузите полученный файл по инструкции из раздела [Свой скин из файла](#свой-скин-из-файла).

## Где взять или нарисовать скин

- Готовые скины: [NameMC](https://namemc.com/minecraft-skins), [The Skindex](https://www.minecraftskins.com);
- Редактор с 3D-рисованием: [Novaskin](https://minecraft.novaskin.me);
- Любой графический редактор (GIMP, Photoshop, Paint.net) с шаблоном скина.

Внутренний слой скина должен быть непрозрачным, во внешнем допускается прозрачность (шапки, очки и т.п.).

## Сброс и обновление

- `/skin clear` &mdash; вернуть стандартный скин (или скин вашей лицензии);
- `/skin update` &mdash; обновить скин, если вы сменили его на лицензионном аккаунте, а на сервере он остался прежним.

## Частые проблемы

- **Чёрные полосы на руках** &mdash; выбрана не та модель. Поставьте скин заново с `slim` или без него;
- **Скин не применился** &mdash; проверьте, что ссылка открывает именно `.png`-файл, а размер &mdash; 64x64;
- **Ошибка о лимите запросов** &mdash; подождите пару минут и повторите команду.
