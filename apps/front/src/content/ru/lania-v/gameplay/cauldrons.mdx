# Котлы

На серверах Lania котлы умеют больше, чем в ванильной игре.

## Затвердевание бетона

Нажмите ПКМ по котлу с водой, держа в руке сухой бетон, чтобы превратить его в бетон. За одно нажатие обрабатывается один блок, и каждое использование тратит один уровень воды в котле.

![Затвердевание бетона](https://czx1jtlf2o.ufs.sh/f/0UHiIrRo6i8c2HT8BBGDOK4vrPw6ExgjZ95TMiUdkAqb1QNo "Затвердевание бетона")

## Грязь

Нажмите ПКМ по котлу с водой, держа в руке землю, чтобы превратить её в грязь. За одно нажатие обрабатывается один блок, и каждое использование тратит один уровень воды в котле.

## Зелья

- ПКМ зельем по **пустому** котлу — зелье выливается в котёл;
- ПКМ пустым пузырьком по котлу с зельем — набрать зелье обратно;
- ПКМ стрелами по котлу с зельем — получить стрелы с эффектом этого зелья.

![Зелья](https://czx1jtlf2o.ufs.sh/f/0UHiIrRo6i8ccVOHQEy5g7AOZNh68Dkvu4BQxKFmLJrVjqU3 "Зелья")

## Медь

Для работы с медными предметами есть два особых котла. Чтобы наполнить котёл, нажмите по пустому котлу ПКМ блоками слизи или мёда: `3` блока наполняют котёл полностью.

- **Слизневый котёл** — ПКМ медным блоком по котлу окисляет (состаривает) его;
- **Медовый котёл** — ПКМ медным блоком по котлу покрывает его воском.

За одно нажатие обрабатывается один блок.
