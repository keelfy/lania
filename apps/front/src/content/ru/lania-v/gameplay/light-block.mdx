# Блок света

На серверах Lania есть возможность получить и использовать блок света в Выживании. Блок света полностью невидим, но создает собой источник освещения. По умолчанию уровень освещения - 15, но это можно изменить нажатием ПКМ по блоку света. 

## Рецепт создания

<CraftingRecipe
  lang="ru"
  shape={['PGP', 'GDG', 'PGP']}
  ingredients={{
    P: 'ender_pearl',
    G: 'glowstone',
    D: 'diamond',
  }}
  result="light"
  amount={16}
/>

<CraftingRecipe
  lang="ru"
  shape={[' G ', 'GBG', ' G ']}
  ingredients={{
    G: 'glowstone',
    B: 'barrier',
  }}
  result="light"
  amount={4}
/>
