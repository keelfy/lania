# Перезагрузки сервера

Сервера переодически перезагружаются для поддержания стабильности игры.

Внутри игры узнать о том, сколько осталось до перезагрузки сервера, можно командой `/ar`. 
Это полезно, потому что иногда сервера могут перезагружаться внепланово.

## Выживание

Ежедневно в `15:00` по гринвичу (GMT+0) происходит перезагрузка сервера.
