# 7TV emotes

This section explains how to install the mod that shows 7TV emotes in the game chat.

## Installing the mod

1. Install the [Fabric](https://fabricmc.net/use) mod loader (if you haven't already).
2. Download the [Streamotes](https://modrinth.com/plugin/streamotes) mod for your game version.
3. Put the mod into the `mods` folder in your game directory.
4. Launch the game.

## Using emotes

Once installed, 7TV emotes show up in the game chat. You can also use them yourself by typing the emote's code word in chat.

To autocomplete an emote code, type `:` in chat and press Tab.

The list of emotes available in chat is [here](https://7tv.app/users/01HEKF7DW0000EXJ0G2972V9JV).
