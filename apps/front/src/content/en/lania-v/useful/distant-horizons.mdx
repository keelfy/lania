# Pre-generated LODs for Distant Horizons

[Distant Horizons](https://modrinth.com/mod/distanthorizons) renders distant chunks as LODs. On a server the mod doesn't load the world automatically, so normally you only see distant chunks where you've already been.

We provide pre-generated LODs so you can see distant chunks at any distance. They work with any setup that has Distant Horizons installed — [keelfy's modpack](/en/wiki/lania-v/useful/modpack) is not required.

- Download the [LOD archive](https://files.keelfy.dev/lania-5-dh-server-data.zip) — it already contains the folders of all worlds

## Installation

If any of the folders from these steps is missing, create it by copying its name from here.

1. Join the server at least once, then leave;
2. Open the game folder (in the Modrinth App, use the "Open folder" button in the profile);
3. Go to the `Distant_Horizons_server_data` folder (or create it);
4. Open the folder named the same as the Lania server in your server list;
   For example, if Lania is called `Lania 5` in your server list, open the `lania+5` folder;
5. Extract the downloaded archive straight into this folder, so that the `xxxx@minecraft@@overworld` folders end up directly inside it, not in an extra subfolder. If asked to replace files, agree;
6. Done. When you join the server, distant chunks should be visible at any distance.
