# keelfy's modpack

<Callout type='important'>
  To install the modpack you need the [Modrinth App](https://modrinth.com/app), a Modrinth account, and a licensed copy of Minecraft.
</Callout>

A modpack by the server's creator &mdash; **keelfy** &mdash; that greatly improves every part of the game, from performance to sound effects. The focus is on performance, visuals, sound, and convenience. The pack also includes mods for singleplayer worlds and server mechanics, listed below.

## System requirements

- Allocate at least 6 GB of RAM to the game.

## Installation

1. Install the [Modrinth App](https://modrinth.com/app) and sign in to your Modrinth account;
2. Open the [modpack invitation](https://modrinth.com/share/K35KZFDC);
3. Accept the invitation and install the modpack in the Modrinth App;
4. Launch the game;
5. Enable the [resource packs you want](#resource-packs) in the game settings;
6. Adjust the rest of the settings to your liking;
7. Read the [common key bindings](#common-key-bindings) and [recommendations](#recommendations);
8. Have fun 🩶

### Updates

When keelfy publishes a modpack update, Modrinth offers it when you launch the game. Review the changes and accept the update in the app.

## Mods

The main mods are grouped by purpose. The full list, including libraries and dependencies, is available in the in-game mod menu.

### Performance and stability

- [Sodium](https://modrinth.com/mod/sodium), [ImmediatelyFast](https://modrinth.com/mod/immediatelyfast) — faster rendering;
- [Lithium](https://modrinth.com/mod/lithium), [Concurrent Chunk Management Engine](https://modrinth.com/mod/c2me-fabric), [ScalableLux](https://modrinth.com/mod/scalablelux) — game logic, chunk, and lighting optimizations;
- [FerriteCore](https://modrinth.com/mod/ferrite-core) — reduced memory usage;
- [EntityCulling](https://modrinth.com/mod/entityculling), [More Culling](https://modrinth.com/mod/moreculling) — skipping hidden objects and faces when rendering;
- [AsyncParticles](https://modrinth.com/mod/asyncparticles) — optimized particle processing;
- [Dynamic FPS](https://modrinth.com/mod/dynamic-fps) — reduced resource usage when the game is idle;
- [Krypton](https://modrinth.com/mod/krypton), [Packet Fixer](https://modrinth.com/mod/packet-fixer), [Server Pinger Fixer](https://modrinth.com/mod/serverpingerfixer) — network optimizations and fixes;
- [Debugify](https://modrinth.com/mod/debugify), [Not Enough Crashes](https://modrinth.com/mod/notenoughcrashes) — bug fixes and easier recovery from crashes;

## Shaders

Choose a shader pack in the graphics settings through Iris. Only one shader pack is used at a time, and shaders can be disabled entirely.

- [Complementary Reimagined](https://modrinth.com/shader/complementary-reimagined) — preserves the Minecraft style;
- [Complementary Unbound](https://modrinth.com/shader/complementary-unbound) — more pronounced visual effects;
- [BSL](https://modrinth.com/shader/bsl-shaders) — bright lighting and rich colors;
- [Bliss](https://modrinth.com/shader/bliss-shader) — atmospheric lighting and environment settings;
- [Photon](https://modrinth.com/shader/photon-shader) — a semi-realistic visual style;
- [MakeUp — Ultra Fast](https://modrinth.com/shader/makeup-ultra-fast-shaders) — adjustable quality and performance;
- [Euphoria Patches](https://modrinth.com/mod/euphoria-patches) — an add-on for Complementary Reimagined and Unbound; patched versions of both are included.

## Recommendations

1. If your PC can't handle the modpack, first try disabling `Distant Horizons` (in the settings menu to the left of the field of view) and shaders.
2. The modpack has a borderless window mode; enable it in the graphics settings by switching the `Fullscreen` option.
3. Ores glow with the `Complementary Unbound` shaders — very handy for exploring caves.
4. Use [Controlling](https://modrinth.com/mod/controlling) search in the controls settings to find and change mod key bindings.

### Arachnophobia

If you have arachnophobia, make sure to disable the `FreshAnimations` resource pack.
