# keelfy's modpack

<Callout type='important'>
  To install the modpack you need the [ModRinth](https://modrinth.com/app) launcher and a licensed copy of Minecraft.
</Callout>

A modpack by the server's creator &mdash; **keelfy** &mdash; that greatly improves every part of the game, from performance to sound effects. All changes are client-side only (no new content or mechanics).

## System requirements

- Allocate at least 6 GB of RAM to the game.

## Installation

1. Install the [ModRinth launcher](https://modrinth.com/app);
2. [Download the modpack for the ModRinth launcher](https://czx1jtlf2o.ufs.sh/f/0UHiIrRo6i8c7ZLxRKkBi3Sy1gbhFoGkCTlIQmcY6Eq9OZeH);
3. Import the modpack into the ModRinth launcher;
4. Launch the game;
5. Enable the [resource packs you want](#resource-packs) in the game settings;
6. Adjust the rest of the settings to your liking;
7. Read the [common key bindings](#common-key-bindings) and [recommendations](#recommendations);
8. Have fun 🩶

## Resource packs

<Callout type='important'>
  You can ignore warnings that resource packs are incompatible with your game version (resource packs with a red background in the list). All of them work.
</Callout>

The modpack comes with the following resource packs; enable only the ones you need:

- [BACAP Language Pack](https://modrinth.com/resourcepack/bacap-language-pack) - translations of the new advancements into Russian;
- [BACAP Better RU](https://modrinth.com/resourcepack/bacap-better-ru) - an improved Russian translation of the new advancements;
- [UniqueDark](https://modrinth.com/resourcepack/unique-dark) - a dark theme for the whole interface;
- `ClientSort Dark Mode` - a small dark theme add-on for the ClientSort mod;
- [VanillaTweaks](https://vanillatweaks.net) - texture bug fixes from VanillaTweaks;
- [Totem Da Capoeira](https://modrinth.com/mod/totem-da-capoeira) - a funny new look for the totem;
- [FreshAnimations](https://modrinth.com/mod/fresh-animations) - better mob animations;
- [xali's Enchanted Books](https://modrinth.com/mod/xalis-enchanted-books) - enchanted book textures that depend on the enchantment;
- [xali's Enchanted Books Addon](https://modrinth.com/mod/xalis-enchanted-books-addon) - extra enchanted book textures;
- [Fancy Crops](https://modrinth.com/mod/fancy-crops) - better crop textures;
- [Low On Fire](https://modrinth.com/resourcepack/low-on-fire) - when you're on fire, the flames are shown lower on the screen;
- [Better Flame Particles](https://modrinth.com/mod/better-flame-particles) - better fire particles;
- [DoorTweak](https://modrinth.com/resourcepack/door-tweaks) - better-looking doors;
- [RAY's 3D Rails](https://modrinth.com/resourcepack/rays-3d-rails) & [RAY's 3D Ladders](https://modrinth.com/resourcepack/rays-3d-ladders) - 3D models for ladders and rails;
- [Better Boat](https://modrinth.com/resourcepack/better-boat) - better-looking boats;
- [SodiumTranslations](https://modrinth.com/resourcepack/translations-for-sodium) - translations of the new graphics settings;
- [BetterSnowCoverage](https://modrinth.com/mod/better-snow-coverage) - snow under blocks surrounded by snow. For example, snow under a flower with snow blocks around it;
- [Borderless Glass](https://modrinth.com/mod/borderless-glass) - borderless glass blocks;
- `BetterBeds` - beds look better and can connect;

**I recommend _enabling_ all resource packs except:**

- `Totem Da Capoeira` (a matter of taste)
- `BetterSnowCoverage` (useful for those living in snowy biomes, which is rare)
- `Borderless Glass` (IMHO it breaks the look of many builds)
- `High Contrast` (UniqueDark looks better)
- `Highlight Extended` (overkill)
- `Programmer Art` (not needed)

## Pre-generated chunk LODs for Distant Horizons

Distant Horizons doesn't load the world automatically on the server; normally you only see distant chunks where you've already been.
We provide pre-generated chunk LODs for Distant Horizons so you can see distant chunks at any distance.

- Download for the [Survival](https://drive.google.com/file/d/1TgeJC5T_txxErIY4rK35jUzroYKPV7bO/view?usp=sharing) server

### Installation

If any of the folders from these steps is missing, create it by copying its name from here.

1. Join the server at least once, then leave;
2. Open the game folder;
3. Go to the `Distant_Horizons_server_data` folder (or create it);
4. Open the folder named the same as the Lania server in your server list;
   For example, if Lania is called `Lania 4` in your server list, open the `lania+4` folder;
5. You'll see several folders like `xxxx@minecraft@@overworld`; you need to put the downloaded file into one of them, depending on which world you want LODs for;

  - Survival: `ok6nqi7ukhgkq@minecraft@@overworld`;
  - Farms: &mdash;

6. Move the downloaded `DistantHorizons.sqlite` into that folder, replacing the existing file;
7. Done. When you join the server, distant chunks should be visible at any distance.


## Recommendations

1. If your PC can't handle the modpack, first try disabling `Distant Horizons` (in the settings menu to the left of the field of view) and shaders.
2. The modpack has a borderless window mode; enable it in the graphics settings by switching the `Fullscreen` option.
3. Ores glow with the `Complementary Unbound` shaders — very handy for exploring caves.
4. If you want the blocks you place to be randomized, check out the [HotbarShuffler](https://modrinth.com/mod/hotbarshuffler) mod included in the modpack.
5. If your keyboard has no function keys, or you don't like the keys the debug key bindings use, you can change them in the controls settings.

### Arachnophobia

If you have arachnophobia, make sure to disable the `FreshAnimations` resource pack.
